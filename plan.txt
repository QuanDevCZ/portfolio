TECH
Static, zero dependencies, no build: index.html + style.css + main.js + assets/. Host on GitHub Pages
(same as other projects) when Quan says so. No paid services.

DRUM (own vanilla JS)
- Cylinder: perspective on wrapper, items rotateX(-step*i) translateZ(r), list rotateX(step*pos).
- Inputs -> one target position: wheel (only while hovering the drum; at first/last card the wheel
  passes through to the page, so page scroll is never hijacked), pointer drag, arrow keys, dot clicks.
- Animate with rAF toward target, easeOutCubic snap to nearest card. Cards beyond ±90° hidden,
  opacity falls off with angle. Front card is a live link.
- prefers-reduced-motion: no intro, instant moves.
- Mobile (<860px): stacked layout, drum smaller; project rows below remain the full list.

MOTION
Intro: name fades in, then drum rises in (<=600ms). Cards below fade up on enter (IntersectionObserver).
Hover lift 2px on rows/cards. Nothing else.
