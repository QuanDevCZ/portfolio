# Portfolio

My personal site: one narrow column of rounded cards, like a link-in-bio page. It covers who I am, what I'm building right now, my recent projects, and how to reach me.

**Live:** https://quandevcz.github.io/portfolio/

## Run it locally

It's a plain static site (`index.html`, `styles.css`, `main.js`) with no build step and no dependencies.

- Windows: double-click `start.cmd`. It serves the folder at http://localhost:4321 and opens Chrome.
- Anywhere else: `npx serve .`, or just open `index.html` in a browser.

## Deploy

GitHub Pages serves it from `main` / root, so pushing to `main` updates the live site.
